# FE25 Test APP UI 设计交付说明

本文档面向 UI 设计师、产品和前端工程师，基于当前 UI 与前端交互基线固化为真实产品 APP 的界面规范。后续无论使用 Capacitor、移动端 WebView、原生壳或跨端框架，都应保持本规范中的信息架构、视觉语言和交互状态。

## 1. 设计目标

- 面向 FE25 产品测试和现场采集场景，优先保证操作清晰、状态明确、误操作可控。
- 保持简约测试工具风格：白底、深蓝文字、蓝色主按钮、圆角卡片、轻量阴影。
- 所有功能入口使用中文文字表达，不使用功能图标作为主要入口。
- 高风险操作必须二次确认，包括断开设备、停止采集、固件升级 / 回退、删除文件、清理缓存。
- 权限缺失、设备未连接、采集中、导出中、升级中等状态必须在 UI 和逻辑层同时体现。

## 2. 视觉规范

### 2.1 色彩

| 用途 | 色值 | 使用场景 |
| --- | --- | --- |
| 主色蓝 | `#176CFF` | 主按钮、当前 Tab、可点击文字、进度条 |
| 深蓝文字 | `#061A4F` | 标题、关键数据、设备编号 |
| 次级文字 | `#6D7894` | 说明文字、提示、单位 |
| 成功绿 | `#1FA65B` | 已连接、采集中、成功提示 |
| 危险红 | `#E64B4B` | 断开、停止、删除、清理、回退按钮 |
| 背景浅灰 | `#EEF3FB` / `#F6F9FF` | 页面外背景、提示卡片 |
| 描边 | `#DFE7F5` | 卡片、输入框、分隔线 |

### 2.2 字体与字号

| 层级 | 建议字号 | 字重 | 说明 |
| --- | --- | --- | --- |
| 大号设备编号 / 百分比 | 40–56px | 800–900 | 设备编号、进度百分比 |
| 页面标题 | 17–22px | 700–800 | 顶部标题 |
| 区块标题 | 16–18px | 700 | 卡片标题、列表标题 |
| 正文 | 14–15px | 400–500 | 说明、表单、列表内容 |
| 辅助文字 | 12–13px | 400 | 单位、提示、说明 |

### 2.3 间距与圆角

- 页面左右安全边距：24px。
- 卡片内边距：14–18px。
- 卡片圆角：16–20px。
- 主按钮高度：48–54px。
- 列表行最小高度：56px。
- iOS / Android WebView 内所有可滚动页面必须支持触控滚动；桌面预览时保留鼠标滚轮滚动。

## 3. 信息架构

```text
启动页
└── 权限申请页
    ├── 首页 / 设备列表
    │   ├── 设备详情 / 数据采集
    │   └── 固件管理
    │       ├── 固件升级 / 回退进度
    │       └── 操作完成
    ├── 数据导出
    │   ├── 设备文件夹
    │   ├── 数据导出中
    │   └── 导出完成
    └── 设置
        ├── 事件标记设置
        ├── 记录区间设置弹窗
        ├── 存储路径设置弹窗
        └── 清理缓存确认弹窗
```

底部 Tab 固定为：首页、导出、设置。非主 Tab 流程页可隐藏底部 Tab，但必须提供明确的完成路径。

## 4. 页面设计要求

### 4.1 启动页

- 展示 `FE25`、`Test APP`、版本号、启动状态。
- 停留约 1 秒进入权限申请页。
- 真实 App 可在此阶段完成本地配置、设备 SDK、日志目录初始化。

### 4.2 权限申请页

- 权限项：蓝牙权限、存储权限。
- 单项开启后显示已开启状态。
- 手动分别开启两个权限后，应自动进入首页。
- 点击“暂不设置”允许进入首页，但蓝牙 / 存储相关功能置灰不可用。

### 4.3 首页 / 设备列表

- 顶部显示 App 名称、版本号、扫描设备按钮，不显示“已连接”总状态。
- 已连接设备行支持：进入详情、升级、断开。
- 可连接设备行只支持连接；点击卡片空白处不进入详情。
- 蓝牙权限缺失时：扫描、连接、断开、升级、详情入口置灰。

### 4.4 固件管理

- 保留当前固件版本和最新版本卡片。
- 目标固件版本使用下拉菜单。
- 目标版本高于当前版本：按钮显示“升级为 xxx 版本”。
- 目标版本低于当前版本：按钮显示“回退为 xxx 版本”，使用危险红。
- 目标版本等于当前版本：按钮禁用。
- 点击操作按钮必须弹出确认弹窗。
- 固件升级 / 回退进度页不显示左上角返回。
- 固件完成页不显示左上角返回，仅保留“完成”。

### 4.5 设备详情 / 数据采集

- 未采集：开始采集可用，停止采集禁用。
- 采集中：展示采集时间，开始按钮变为“采集中...”，停止按钮可用。
- 事件标记区使用网格按钮，“删除上一次标记”替代“其他”事件按钮。
- 未采集点击事件标记提示“请先开始采集”。
- 删除上一次标记仅在采集中且存在标记时可用。
- 实时数据区使用两列数据卡片，运行状态随采集状态更新。

### 4.6 数据导出

- 底部“导出”直接进入设备选择页，不再出现导出方式选择页。
- 设备行右侧使用简约箭头，点击整行进入设备文件夹。
- 文件夹内显示：文件名、文件大小；文件名包含时间和事件类型。
- 文件支持多选、全选、批量导出、批量删除。
- 三个操作按钮必须同排合理布局：全选 / 导出 / 删除。
- 导出完成页不显示左上角返回，支持微信、飞书、钉钉、邮箱分享。

### 4.7 设置

- 保留：事件标记设置、记录区间设置、当前存储路径、清理缓存、关于。
- 事件标记设置和记录区间设置右侧使用简约箭头。
- 当前存储路径可点击调整位置，右侧显示路径和箭头。
- 清理本地测试数据改为“清理缓存”。
- 采集中不允许清理缓存。

## 5. 组件状态规范

### 5.1 按钮状态

| 状态 | 样式 | 场景 |
| --- | --- | --- |
| 主按钮 | 蓝底白字 | 扫描、开始采集、开始导出、完成 |
| 次按钮 | 白底蓝字描边 | 取消、分享渠道、后台导出 |
| 危险按钮 | 红底白字 | 断开、停止、删除、清理、回退 |
| 禁用按钮 | 浅灰底灰字 | 权限缺失、未选择文件、当前版本无需操作 |

### 5.2 Toast

- 展示位置需要避开底部 Tab 和手机底部指示条。
- 常见文案：
  - `扫描完成`
  - `请先开启蓝牙权限。`
  - `请先开启存储权限。`
  - `已标记：确认中鱼　　时间：00:01:30`
  - `已删除上一次标记：确认中鱼　　时间：00:01:30`
  - `采集已停止，数据已保存。`
  - `导出任务已转入后台`
  - `缓存清理完成。`

### 5.3 弹窗

- 使用半透明遮罩 + 白色圆角弹窗。
- 高风险操作弹窗按钮顺序：左取消，右危险确认。
- 表单弹窗校验错误在输入项下方显示，不关闭弹窗。

## 6. 真实产品接入时的 UI 验收重点

- 权限缺失时，不仅提示，也要让相关入口视觉置灰并不可点击。
- 所有异步任务必须有进度反馈和完成 / 失败状态。
- 固件升级 / 回退过程中不提供左上角返回。
- 导出完成、固件完成等终态页以主按钮作为唯一返回主流程方式。
- 文件删除、缓存清理等不可逆操作必须二次确认。
- 所有可滚动页面在 iOS / Android 真机内必须支持触控滚动，在桌面预览时支持鼠标滚轮。
