# FE25 Test APP 免安装应用程序 Demo

这是一个基于 Electron 壳封装的 **免安装桌面应用程序 Demo**，内部仍使用本地 HTML/CSS/JavaScript 渲染 FE25 Test APP 手机端原型；打包后可下载解压并直接双击运行，不需要后端服务、不依赖在线 CDN。

## 如何运行

### 产品评审人员：下载后直接打开

如果你拿到的是已经打包好的版本：

- Windows：双击 `FE25-Test-APP-1.0.0-portable.exe`。
- macOS：双击 `FE25 Test APP.app`。
- Linux：双击或执行 `FE25 Test APP.AppImage`。

应用启动后会进入独立桌面窗口，不需要打开浏览器，也不需要安装到系统。

### 开发 / 打包人员：生成免安装包

首次打包需要安装 Electron 依赖：

```bash
npm install
```

本地启动桌面应用：

```bash
npm start
```

生成 Windows 免安装便携版：

```bash
npm run dist:win
```

打包产物会输出到 `release/` 目录，交付给评审人员后可直接双击运行。

### 备用预览方式

`index.html` 仍可作为本地页面预览入口保留，但正式交付建议使用上面的 Electron 免安装包。

## 项目结构

```text
.
├── package.json # Electron 启动与免安装打包配置
├── main.js      # 桌面应用主进程入口，创建独立应用窗口
├── index.html   # 渲染入口，包含手机容器、状态栏、弹窗和 Toast 挂载点
├── style.css    # 离线样式，模拟手机外壳、卡片、按钮、Tab、弹窗和进度条
├── app.js       # 单页应用逻辑，负责视图切换、模拟状态、进度和交互
├── script.js    # 旧页面缓存兜底脚本，遇到旧入口时自动切换到 FE25 Demo
└── README.md    # 运行、打包方式和功能说明
```

## 已实现功能

- 启动页：展示 FE25、Test APP、版本号和启动状态，1 秒后进入权限申请页。
- 权限申请页：模拟蓝牙权限、存储权限的开启状态；点击“暂不设置”后，依赖对应权限的扫描、连接、采集、导出、清理等功能会置灰且不可用。
- 首页 / 设备列表页：展示已连接设备、可连接设备，支持扫描设备、连接、断开二次确认、进入设备详情和固件管理。
- 固件管理：保留当前版本和最新版本卡片，通过目标版本下拉菜单统一触发升级或回退，按钮文案随所选版本自动变化；内容超出时支持鼠标滚轮滚动查看。
- 固件升级进度：模拟 0% 到 100% 的自动进度，并在完成后进入升级完成页。
- 设备详情 / 数据采集：支持开始采集、采集计时、停止采集二次确认、事件标记 Toast，并用“删除上一次标记”替代“其他”事件按钮。
- 数据导出：底部“导出”直接进入设备选择；按设备进入设备存储文件夹，展示采集数据文件名与大小，支持多选导出、多选删除，并在导出完成后模拟分享到微信、飞书、钉钉和邮箱。
- 设置页：事件标记设置、记录区间设置、当前存储路径、清理缓存二次确认、关于信息。
- 事件标记设置：支持开关切换、恢复默认、保存，并限制至少保留一个事件类型开启。
- 记录区间设置：输入框仅保留数字，并校验事件前 1–120 秒、事件后 1–30 分钟。
- Toast 和弹窗：统一使用半透明遮罩、白色圆角弹窗和底部提示。

## 模拟数据说明

本 Demo 不连接真实硬件，也不调用任何后端接口。以下内容均为前端模拟：

- 设备连接、设备断开。
- 固件升级、固件回退、设备重启、升级进度。
- 数据采集、事件标记、采集时长、实时传感器数据。
- 数据导出、导出文件、后台导出、导出完成。
- 本地测试数据占用和清理。
- 存储路径、APP 版本号、缓存占用。

## 设计说明

- 使用白底、深蓝文字、蓝色主按钮、圆角卡片和轻量阴影，尽量贴近参考图中的测试工具风格。
- 页面被固定宽高的手机容器包裹，模拟移动端 APP 外观。
- 全部功能入口均使用中文文字表达，不使用功能 ICON。
- 页面切换由 `app.js` 控制，在 Electron 独立窗口内完成，不刷新页面。
- 所有样式和脚本均为本地文件，不依赖 CDN 或后端服务。
- `main.js` 只加载本地 `index.html`，关闭 Node 注入，适合作为评审用免安装原型壳。
