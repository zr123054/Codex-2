# FE25 Test APP iOS/Android 可安装应用基线

FE25 Test APP 是一个面向 iOS 和 Android 的可安装应用前端基线，当前使用本地 HTML/CSS/JavaScript 完成全部页面、基础交互、状态流转、弹窗、Toast、进度条和离线数据闭环。项目通过 Capacitor 承载 Web 前端，后续可接入真实设备 SDK、系统权限、文件能力和后端接口。

> 当前版本不依赖 CDN，也不需要后端服务即可预览完整交互；接入真实产品时，按 `docs/FRONTEND_ENGINEERING_SPEC.md` 与 `BACKEND_DEVELOPMENT.md` 替换本地数据源、接入设备 SDK 和后端接口。

## 如何运行和生成移动端工程

### 1. 安装依赖

```bash
npm install
```

### 2. 生成原生工程

首次生成 iOS / Android 工程：

```bash
npm run cap:add:ios
npm run cap:add:android
```

> iOS 工程需要在 macOS + Xcode 环境中生成和打开；Android 工程需要 Android Studio / Android SDK。

### 3. 同步前端资源到原生工程

每次修改 `index.html`、`style.css`、`app.js` 或配置后执行；脚本会先生成临时 `www/` Web 资源目录，再同步到原生工程：

```bash
npm run cap:sync
```

### 4. 打开原生工程并安装到设备

```bash
npm run ios
npm run android
```

在 Xcode 或 Android Studio 中选择真机 / 模拟器运行，即可安装到 iOS 或 Android 设备。

### 备用预览方式

`index.html` 可作为本地页面预览入口保留；正式真机安装和调试请使用 Capacitor 生成的 iOS / Android 工程。

## 项目结构

```text
.
├── package.json          # Capacitor 依赖、移动端工程脚本与应用元信息
├── capacitor.config.json # iOS / Android 应用 ID、应用名、Web 资源目录和平台配置
├── www/                  # 同步前由 npm 脚本生成的 Capacitor Web 资源目录，不提交
├── index.html            # 渲染入口，包含应用容器、弹窗和 Toast 挂载点
├── figma-html-to-design.html # Figma HTML to Design 导入页面，尺寸为 440 × 956
├── style.css             # 本地样式，包含移动端适配、卡片、按钮、Tab、弹窗和进度条
├── app.js                # 单页应用逻辑，负责视图切换、状态流转、进度和交互
├── docs/                 # UI 设计规范、前端工程接入说明和后端 UI 交付文件
├── BACKEND_DEVELOPMENT.md # 后端开发资料，包含接口、数据模型和联调验收清单
└── README.md             # 运行、移动端生成方式和功能说明
```

## 已完成的 UI 与前端交互

- 启动页：展示 FE25、Test APP、版本号和启动状态，1 秒后进入权限申请页。
- 权限申请页：处理蓝牙权限、存储权限状态；点击“暂不设置”后，依赖对应权限的扫描、连接、采集、导出、清理等功能会置灰且不可用。
- 首页 / 设备列表页：展示已连接设备、可连接设备，支持扫描设备、连接、断开二次确认、进入设备详情和固件管理。
- 固件管理：保留当前版本和最新版本卡片，通过目标版本下拉菜单统一触发升级或回退，按钮文案随所选版本自动变化；内容超出时支持触控滚动和鼠标滚轮滚动。
- 固件升级 / 回退进度：从 0% 到 100% 自动推进；选择低版本时进度页标题显示“固件回退”，选择高版本时显示“固件升级”；进度页与完成页均不显示左上角返回。
- 设备详情 / 数据采集：支持开始采集、采集计时、停止采集二次确认、事件标记 Toast，并用“删除上一次标记”替代“其他”事件按钮。
- 数据导出：底部“导出”直接进入设备选择；按设备进入设备存储文件夹，设备行右侧使用简约箭头提示可进入；文件夹内展示采集数据文件名与大小，支持多选导出、多选删除，并在导出完成后展示微信、飞书、钉钉和邮箱分享入口。
- 设置页：事件标记设置、记录区间设置、当前存储路径调整、清理缓存二次确认、关于信息。
- 事件标记设置：支持开关切换、恢复默认、保存，并限制至少保留一个事件类型开启。
- 记录区间设置：输入框仅保留数字，并校验事件前 1–120 秒、事件后 1–30 分钟。
- Toast 和弹窗：统一使用半透明遮罩、白色圆角弹窗和底部提示。

## 当前离线数据说明

当前版本不连接真实硬件，也不调用后端接口。以下内容由前端本地状态驱动，用于完整演示真实产品交互路径：

- 设备扫描、连接、断开。
- 固件升级、固件回退、设备重启、升级 / 回退进度。
- 数据采集、事件标记、采集时长、实时传感器数据。
- 数据导出、导出文件、后台导出、导出完成与分享反馈。
- 缓存占用、存储路径、APP 版本号。

## 接入真实产品时的替换范围

- 将 `app.js` 中的设备、文件、固件、采集和设置本地状态替换为真实接口或设备 SDK 数据源。
- 将固件进度和导出进度的定时器替换为后端任务轮询、WebSocket/SSE 或设备 SDK 进度回调。
- 将权限、蓝牙、文件保存、系统分享等能力通过 Capacitor 插件、自定义原生插件或跨端框架桥接。
- 保留当前 UI 禁用态、二次确认、Toast、表单校验和流程页规则；后端仍需做同样校验。

## 设计说明

- 使用白底、深蓝文字、蓝色主按钮、圆角卡片和轻量阴影，保持简约测试工具风格。
- 在 iOS / Android 真机中页面铺满 WebView，并使用安全区适配避开系统状态栏和底部手势区域。
- 在桌面浏览器预览时保留手机外壳容器，方便评审时查看移动端效果。
- 全部功能入口均使用中文文字表达，不使用功能图标作为主要入口。
- 页面切换由 `app.js` 控制，不刷新页面。
- 所有样式和脚本均为本地文件，不依赖 CDN 或后端服务。
