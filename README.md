# FE25 Test APP 离线网页 Demo

这是一个纯前端、可离线运行的手机 APP 原型 Demo，用于模拟 **FE25 Test APP** 的主要页面结构和基础交互流程，适合产品评审、演示和交互走查。

## 如何运行

方式一：直接打开文件。

1. 下载或复制本项目目录。
2. 使用本地浏览器直接打开 `index.html`。
3. 页面会先显示启动页，1 秒后自动进入权限申请页。

方式二：使用本地静态服务预览（可选）。

```bash
python3 -m http.server 8080
```

然后在浏览器访问：

```text
http://localhost:8080
```

## 项目结构

```text
.
├── index.html   # 页面入口，包含手机容器、状态栏、弹窗和 Toast 挂载点
├── style.css    # 离线样式，模拟手机外壳、卡片、按钮、Tab、弹窗和进度条
├── app.js       # 单页应用逻辑，负责视图切换、模拟状态、进度和交互
└── README.md    # 运行方式和功能说明
```

## 已实现功能

- 启动页：展示 FE25、Test APP、版本号和启动状态，1 秒后进入权限申请页。
- 权限申请页：模拟蓝牙权限、存储权限的开启状态，以及全部开启 / 暂不设置流程。
- 首页 / 设备列表页：展示已连接设备、可连接设备，支持扫描设备、连接、断开二次确认、进入设备详情和固件管理。
- 固件管理：展示当前版本、最新版本、升级、回退、升级说明和确认弹窗。
- 固件升级进度：模拟 0% 到 100% 的自动进度，并在完成后进入升级完成页。
- 设备详情 / 数据采集：支持开始采集、采集计时、停止采集二次确认、事件标记 Toast、实时数据展示。
- 数据导出：首页、按设备导出、多设备导出、导出进度、后台导出和导出完成流程。
- 设置页：事件标记设置、记录区间设置、扫描超时弹窗、清理本地测试数据二次确认、关于信息。
- 事件标记设置：支持开关切换、恢复默认、保存，并限制至少保留一个事件类型开启。
- 记录区间设置：输入框仅保留数字，并校验事件前 1–120 秒、事件后 1–30 分钟。
- Toast 和弹窗：统一使用半透明遮罩、白色圆角弹窗和底部提示。

## 模拟数据说明

本 Demo 不连接真实硬件，也不调用任何后端接口。以下内容均为前端模拟：

- 蓝牙扫描、设备连接、设备断开。
- 固件升级、固件回退、设备重启、升级进度。
- 数据采集、事件标记、采集时长、实时传感器数据。
- 数据导出、导出文件、后台导出、导出完成。
- 本地测试数据占用和清理。
- 存储路径、APP 版本号、蓝牙扫描超时时间。

## 设计说明

- 使用白底、深蓝文字、蓝色主按钮、圆角卡片和轻量阴影，尽量贴近参考图中的测试工具风格。
- 页面被固定宽高的手机容器包裹，模拟移动端 APP 外观。
- 全部功能入口均使用中文文字表达，不使用功能 ICON。
- 页面切换由 `app.js` 控制，不刷新浏览器。
- 所有样式和脚本均为本地文件，不依赖 CDN 或后端服务。
