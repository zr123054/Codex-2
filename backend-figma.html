四、联调流程与验收点

Acceptance checklist

固件任务验收

  1. 选择高版本创建任务，后端返回 action=upgrade。
  2. 选择低版本创建任务，后端返回 action=rollback。
  3. 进度接口或 WebSocket 从 0 推送到 100。
  4. 完成后设备版本更新为目标版本。
  5. 回退任务进度页标题必须显示“固件回退”。

导出任务验收

  1. 导出 Tab 直接进入设备选择，不出现多设备导出入口。
  2. 设备文件夹返回文件名、大小、事件类型、时间。
  3. 未选择文件时导出和删除按钮不可用。
  4. 导出完成页无左上角返回，仅支持分享和完成。
  5. 分享渠道返回成功或失败提示。

采集任务验收

  1. 开始采集创建会话并返回 sessionId。
  2. 标记事件记录相对采集时间。
  3. 删除上一次标记只删除当前会话最后一条未删除标记。
  4. 停止采集保存会话、时长和文件。
  5. 采集中不允许清理缓存。

权限与设置验收

  1. 权限未开启时客户端置灰，后端仍需校验请求合法性。
  2. 记录区间后端校验：前 1-120 秒，后 1-30 分钟。
  3. 事件标记至少保留一个启用项。
  4. 存储路径仅作为模拟配置或真实环境的路径偏好。
  5. 清理缓存是高风险操作，必须二次确认。
